# 室內配線乙級 第二站 · 互動電路實驗室

技術士技能檢定「室內配線（屋內線路裝修）乙級」**第二站**八題控制電路的互動模擬器。

不是動畫播放，而是**真正的邏輯模擬**：每一題都建立了完整的電路資料結構，模擬引擎逐幀反覆收斂求解（含自保持迴路、限時電驛、保持電驛、交替電驛、計數器），再驅動繪圖。你按下按鈕，電路就照它真正的邏輯反應。

## 線上使用

**<https://yuan-5149.github.io/station2-circuit-lab/>**

或下載 `index.html` 直接用瀏覽器開啟 —— 單一檔案、無外部相依、不需網路。

## 特色

### 三色通電追蹤

- **紅** — 有電流通過
- **琥珀** — 有電壓但迴路未成立
- **灰** — 無電

琥珀色這一層是關鍵。它讓學習者看懂「為什麼按了沒反應」：電壓送到哪個接點就斷了，一眼就知道卡在哪個條件。

### 依官方試題線路圖呈現

採 CNS 縱向控制電路圖畫法，與試題本一致：

- 上下匯流排（R／T，各經 D-F 熔絲）、垂直迴路
- 接點為兩條粗橫棒，b 接點加斜線
- 按鈕為端子圈＋側邊推桿；限時接點為端子圈＋▷ 三角
- TH-RY 為底部共用交叉剪刀狀 c 接點
- 線圈為 ○（內書元件名）、指示燈為 ⊗
- COS 旋轉刀形接點、FS／LS 機械操作開關

### 主電路 ＋ 控制電路

第 1～6 題同時提供左半**主電路（動力電路）**，元件跟著控制電路即時動作：

- 第 1、2 題：MCS 短接 X-Y-Z（Y 啟動）→ MCD 接成 Δ，看得見 Y-Δ 怎麼變
- 第 5 題：Tr 變壓器 → REC 橋式整流 → MCB 注入直流，直流煞車的來源一目了然
- 第 3、4 題：MS1／MS2 電磁開關、兩台馬達獨立 TH-RY

可用標題列切換「全圖／主電路／控制電路」。

第 7、8 題官方本來就是單張圖，故不提供切換。

### 現場設備動畫

馬達 Y／Δ 繞組與轉向、水塔與污水槽水位電極、大門開度與光電光束、ATS 轉動指針、沖床衝程與計數器、監視盤儀表讀值。

### 動作分解導引

32 個操作情境、172 個步驟，敘述沿用教材原文。可逐步推進、點步驟跳段、或自動播放；也可以完全丟開導引，自己用操作盤實驗。

### 深／淺色主題

右上角切換，選擇會記住。兩套主題的對比度都經過量測。

## 技術

- 單一 HTML 檔，原生 JS + SVG，零相依、零建置
- 電路以宣告式資料結構描述（串並聯、接點、線圈、計時器），模擬引擎與繪圖引擎共用同一份資料
- 每幀：前向傳遞求電壓 → 反向傳遞判斷迴路是否成立 → 收斂迭代（處理自保持）→ 更新計時器 → 邊緣觸發（交替電驛／計數器）→ 機構模擬（水位、門位、ATS 角度）
